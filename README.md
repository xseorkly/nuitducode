# Objectif Nuit du C0de — Préparation Scratch

Site de présentation de la [Nuit du Code](https://nuitducode.forge.apps.education.fr/) et du parcours de préparation « Objectif Coding » pour Scratch (Fehmi Klabi, EF2D Technologie, AEFE).

## Contenu

- **La Nuit du Code** : principe, catégories, calendrier 2026-2027, règles et grille d'évaluation
- **Parcours de préparation** : séquences #0 à #9, séquence passerelle et 4 bonus, avec pour chacune
  - un **côté élève** (mission, étapes, astuces, auto-vérification)
  - un **côté prof** (objectifs, compétences, déroulé, vigilance, différenciation, évaluation)
  - la fiche PDF lisible en ligne et téléchargeable
- **7 game packs Scratch** (.sb3) téléchargeables
- **18 tutos vidéo**, page **Ressources**, guide d'organisation et **diaporama** de présentation

## Structure

| Dossier | Contenu |
|---|---|
| `index.html` | le site (une seule page, navigation par ancres) |
| `data.js` | contenu des séquences, game packs et tutos |
| `files/` | fiches PDF et game packs `.sb3` |
| `pages/` | pages des fiches en images (lecteur en ligne) |
| `img/` | aperçus des fiches et des game packs |

Le site est publié automatiquement avec GitHub Pages à chaque push sur `main` (workflow `.github/workflows/static.yml`).

Pour ouvrir un game pack : Scratch → Fichier → « Charger depuis votre ordinateur » → choisir le fichier `.sb3`.
